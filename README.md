# Asiimwe Gilbert - Portfolio

A modern, high-performance portfolio for **Asiimwe Gilbert**, an AI Full-Stack & Systems Engineer. Built with Next.js, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Tech Stack**: Next.js 15 (App Router), TypeScript, Tailwind CSS, Framer Motion.
- **Design Language**: Deep Midnight / Cyberpunk Professional aesthetic.
- **Animations**: 
  - Interactive "Binary Rain" hero background.
  - Smooth "Reveal on Scroll" animations for all sections.
  - Magnetic hover effects and staggered entrance animations.
- **Modular Architecture**: Cleanly separated components for scalability.
- **Responsive**: Mobile-first design optimized for all devices.

## 📂 Structure

- `src/components`:
  - `layout/`: Navbar, Footer.
  - `sections/`: Hero, About, Projects, Academic, Skills, Contact.
  - `ui/`: Reusable primitives like the `Section` wrapper.
- `src/data/`: Centralized `portfolio.ts` for easy content updates.
- `legacy/`: Original static site files preserved for reference.

## 🛠️ Development

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🏗️ Build

To create a production-ready build:

```bash
npm run build
```
