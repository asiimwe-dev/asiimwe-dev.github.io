# Multi-Year Learning Roadmap Timetable

**Based on the layered approach: Durable capability over temporary intensity**

**Core Philosophy**  
Build layers like a tree: roots first (strong fundamentals), then branches. One meaningful project per semester. Maintain previous layers while adding new ones.

**Personal Operating System (Ongoing)**
- Sleep: 7–8 hours (non-negotiable)
- Exercise: 3–5 times per week
- Reading: 20 pages daily
- Reflection: Weekly + Monthly + Annual reviews
- Deep Work: 2 focused hours daily (7–9 PM)
- Social Media: Intentional consumption, create more than consume
- AI: Use as multiplier after understanding foundations

---

## High-Level Annual Structure

| Year | Primary Focus                  | Semesters     | Key Milestone |
|------|--------------------------------|---------------|---------------|
| 1    | Layer 1: Software Generalist   | 1–2           | Production-quality full-stack apps |
| 2    | Layer 1 + Layer 2: Data & Predictive Systems | 3–4 | Predictive features in apps |
| 3    | Layer 3: Security              | 5–6           | Secure all previous projects |
| 4+   | Layer 5: Domain Specialization + Layer 4: AI Leverage | 7+ | Industry-specific solutions |

**Ongoing Every Semester/Year:**
- Soft skills (communication, writing, presenting)
- One end-to-end project
- Maintain previous layers (refactoring/review)

---

## Core Weekly Routine (Applies to All Years)

**Morning (6:00 – 8:00 AM)**
- 6:00–7:00: Exercise
- 7:00–7:30: Reading (tech + non-tech)
- 7:30–8:00: Planning + reflection

**Main Block (9:00 AM – 5:00 PM)**  
University / Job / Deep work (no multitasking)

**Evening Deep Work (7:00 – 9:00 PM)** – One focus per day  
**Saturday:** Full project integration  
**Sunday:** Rest + Weekly Review

## Year 4+: Layer 5 – Domain Specialization + AI Leverage

**Maintain prior layers (1–2 days/week)**

**Evening Rotation Example:**
- 3 evenings: Domain research + practitioner interviews
- 2 evenings: Building domain-specific features
- Saturday: Large integrated project (e.g., Predictive maintenance for chosen industry)
- Use AI for refactoring, tests, documentation, threat analysis (never as substitute for thinking)

**Example Domains:**
- Oil & Gas: SCADA, sensors, predictive maintenance
- Agriculture: Weather, soil, supply chain prediction
- Healthcare: EMRs, regulations, patient workflows

**Semester Project Rule (Every Semester):**
One meaningful, deployed, well-documented project that integrates current + previous layers. Update portfolio.

- **Monthly:** Habit review (sleep, exercise, consistency)

Become someone who can repeatedly learn new domains, build valuable systems, and sustain health, relationships, and curiosity for decades.
